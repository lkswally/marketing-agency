# Definition of Done — Alpha Pilot (MKT-8A)

Quality bar to declare the pilot "done". Run this at the end
of each cycle. If any item is `❌`, the cycle is NOT done
yet — fix or file a `PENDING` item.

## Pipeline artifacts

- [ ] `strategy/current.json` exists, validates.
- [ ] `creative_asset_pack/current.json` exists, validates.
- [ ] `visual_direction_pack/current.json` exists, validates.
- [ ] `approval_pack/current.json` exists, validates.
- [ ] `campaign_execution_task_pack/current.json` exists, validates.
- [ ] `image_generation_job_pack/current.json` exists, validates
      and `by_state["generated"] == 0`.
- [ ] `image_provider_recommendation_pack/current.json` exists
      and `by_dry_run_status` contains only `dry_run` /
      `skipped_blocked` / `skipped_manual`.

## ATLAS handoff (when scope includes design / web)

- [ ] At least one `atlas_handoff_brief/current.json` exists.
- [ ] The brief MD is shareable as-is (no operator-only
      jargon, no placeholders).
- [ ] All `acceptance_criteria` items are concrete and testable.
- [ ] If upstream blocks publish, the handoff MD carries the
      WARNING banner.

## Analytics + iteration loop (when scope includes a real campaign cycle)

- [ ] `metrics_snapshot/current.json` has ≥ 1 row per active source.
- [ ] `optimization_recommendation_pack/current.json` exists.
- [ ] `campaign_feedback_pack/current.json` exists.
- [ ] `next_campaign_iteration_plan/current.json` exists.
- [ ] Google Ads sub-loop (if used): `google_ads_insight_pack`
      + `ads_feedback_bridge_pack` exist.

## Quality gates

- [ ] No `blocks_publish=True` anywhere — OR the operator has
      a documented reason to ship anyway.
- [ ] `python -m pytest -q` exits 0.
- [ ] `ruff check .` exits 0.
- [ ] Audit JSONL is intact — no missing days during the pilot.

## Safety gates

- [ ] No real provider was called outside the operator's
      explicit consent.
- [ ] No real publication / email / Ads write happened.
- [ ] No credential was committed to the repo.
- [ ] No PNG / JPG / WebP was generated by MARKETING-AGENCY-OS.
- [ ] The ATLAS handoff was transferred manually — no
      automation reached into ATLAS.

## Operator + reviewer sign-off

- [ ] Account lead reviewed and approved every deliverable.
- [ ] Reviewer signed off the approval pack.
- [ ] Client received the deliverables and acknowledged them.
- [ ] Retrospective notes captured in `data/<slug>/_retro.md`
      (free-form).
- [ ] Surprises captured in `PENDING.md` as new `P-*` entries.

## Closeout

- [ ] `data/<slug>/` and `outputs/<slug>/` zipped and stored.
- [ ] If a follow-up cycle is planned, re-run the Definition
      of Ready before starting.

When every box is checked, the cycle is **done**.
